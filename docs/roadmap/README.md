# Roadmap — FPS Brandpreventie

Dit is de uitgesplitste roadmapdocumentatie. Het hoge-niveau-overzicht (de drie sporen) en de harde **Ontwikkelstop**-regel staan in [`replit.md`](../../replit.md); de detailuitwerking per fase staat hieronder.

- [Gebouwd](./gebouwd.md) — afgeronde fasen met definitief model (V1.2 Bibliotheek & documentstructuur; V1.3 Spots & uitvoering; AI-fotoherkenning spotafwerking; V1.4 Opleverrapportage; DMS / documentenbibliotheek incl. het V1.5-bevriezingsdeel op dossiers).
- [Actief](./actief.md) — vastgelegde fasen (V1.5 Rapportenmodule — deels gebouwd via V1.4, restscope: centrale rapportenbibliotheek-UI, CRM/onderhoud/klantportaal-koppeling, volledige reactietermijn-statusmachine).
- [Document Design System](./document-design-system.md) — vastgelegde, modulebrede documentmotor (drie templatefamilies + per-werkmaatschappij centraal beheer); NIET vooruit bouwen, pas ná formeel akkoord.
- [Parallel spoor](./parallel-spoor.md) — Fase 1-basis met formeel akkoord, parallel aan de hoofdroadmap gebouwd (HRM/Personeel; Dossiermodule; Offerte Intelligence — alleen voorbereiding, geen AI, geen verzending).
- [Geparkeerd](./geparkeerd.md) — NIET vooruit bouwen (S.G. Constructies — herzien: samengestelde-constructie spottype + constructietemplates; biometrisch inloggen mobiele app; toolbox & berichten met leesbevestiging (mobiel); V3.0 Personeel / HRM-module FPS Groep; AI Brandveiligheidsmanager / AI Calculator / Klantmodule; [Adaptive Workspace Engine](./adaptive-workspace-engine.md) — centrale, lerende UI-personalisatie, pas ná V1.5/DDS).
- [Fase 2 — Bedrijfsbesturing, calculatie & managementinformatie](./fase-2-bedrijfsbesturing.md) — strategische horizon NÁ de huidige Connect-roadmap; geen bouwopdracht, NIET vooruit bouwen. Connect groeit van operationeel platform naar bedrijfsbesturingssysteem (calculatie/projectbegroting, projectcontrol, project health, klantintelligence, capaciteit, managementdashboard, eenrichtingskoppeling Connect → AccountView).
- [Update-voorblad bij login](./update-voorblad-login.md) — voorstel (ontwerp + datamodel), nog geen formeel akkoord, NIET bouwen: versiebeheer-/changelogpopup bij eerste login ná een nieuwe release, per gebruiker bijgehouden.

**Ontwikkelstop blijft leidend:** per fase pas bouwen ná formeel akkoord op die fase; start geen latere fasen vooruit. Het parallelle spoor is een uitzondering met expliciet formeel akkoord, en uitsluitend voor de Fase 1-basis (de diepere HRM- en AI-uitwerking blijft geparkeerd).
